# 設計書: **回転パルスによる伝達利得の単純系再現** (2026-08-29)

> **本書は設計のみ。実測GOは別途。** エンジン・`bulletref` 非改変、重力 `98` 固定、修正実装なし。
> 前提: タスク130 で `f784` を **「極端質量比の鎖への一撃に対する伝達利得の三者分岐」**
> (`bulletref` 0.24 / 参照 1.00 / 当エンジン 1.62) と再定義。
> タスク131 で **並進段差では伝達が測れない**ことが実測で判明 (末端が回転しない)。

## 1. 駆動の形 — **回転パルス**

### 1-1. なぜ回転か

モデルZ の `f784` は **頭の回転の一撃**である (頭 `w` が `0.63 → 11.40 °/60Hz-frame`)。
**全ロック鎖に並進を与えても鎖は剛体的に平行移動するだけで末端は回転しない** —
タスク131 で実測 (`F301` で根元 **16.11°/f** に対し末端 **0.0000°/f**)。
**`G = w_末端 / w_根元` を測るには根元が回る駆動が要る。**

### 1-2. 軸の選定 — ★**Z 軸 1 軸に固定**

鎖は `センター(0,12,0)` から **-Y 方向**に垂れる。

- **Z 軸まわりの回転**は `(0,-L,0)` を `(+L sinθ, -L cosθ, 0)` へ動かす = **+X 方向に振り出す**
- 既存の並進段差も **+X 方向**だったので、**振れる平面 (XY) が既存試料と揃う**
- X 軸まわりだと -Z 方向へ振れ、既存の観察・図と平面が変わる

→ **Z 軸 1 軸。多軸にしない** (軸が増えると `G` が軸ごとに割れて解釈が増える)。

### 1-3. 付与先 — センター。★**この代理の妥当性**

| | モデルZ | `chain35` |
|---|---|---|
| 鎖の親 | **頭** (`鎖L_0_1` の親) | **根元** (`鎖1` の親) |
| 駆動されるもの | 頭ボーン (VMD キーあり) | **センター** (`根元` は**キー無し**が受入検査の既定) |

`根元` にキーが無いのは **`R0` を `mode0` (ボーン追従) にして鎖の吊り元とするため**で、
**`根元` はセンターの子**である。したがって**センターを回せば `根元` も同じだけ回り、鎖の吊り元が回る**。

> ★**構造対応は成立する**: どちらも「**鎖の直上の剛体が回り、その回転が鎖へ入る**」という同じ形になる。
> **相違点は 1 つ** — モデルZ では頭が**剛体としても存在**し (`body 0 name=頭`)、
> 鎖と**接触もし得る**のに対し、`chain35` の `R0` は接触なし (`group=0 mask=0x0000`)。
> **本設計は「接触のない純粋な伝達」を測る**ものであり、接触が絡む経路は範囲外である。
> (接触経路はタスク125 で「平時窓では一度も起きていない」と実測済み。`f784` 前後は未検査で、
> ★**これは持ち越しの限定として結果に必ず添える**)

### 1-4. 角度プロファイル — モデルZ の頭の振りを写す

モデルZ の頭 `w` (60Hz 毎フレーム角): `0.63 → 3.12 → 7.25 → **11.40** → 10.62 → 4.79 → 1.72`。
**0 → ピーク → 0 の S 字**で、**総振り角は約 80°**。

30fps キーの**累積角**を S 字に置き、線形補間で 60Hz の毎フレーム角がピークを持つようにする:

| 30fps キー | 300 | 301 | 302 | 303 | 304 | 305 | 306 | 1200 | 1201 | 2100 |
|---|---|---|---|---|---|---|---|---|---|---|
| 累積角 (総角 A に対する比) | 0 | 0.0375 | 0.175 | 0.4625 | 0.775 | 0.9375 | **1.0** | 1.0 | 0 | 0 |

- **`F306` まで振り、`F1200` まで保持、`F1201` で戻し、`F2100` まで静置** (既存段差VMD と同じ骨格)
- **並進は 0**、**Z 軸回転のみ**

**`ladder` が資格を持たない以上、単純系では検査できない** — これは限定として記録する。

## 5. ★事前の物理検算 (**測る前に書く**)

> **全ロック鎖 (`lo=hi=0` の 6DOF ロック) が理想剛体なら、鎖全体が一体で回り `G = 1` が理論値である。**

したがって:

- **`G = 1` からの逸脱は、そのソルバが<ruby>ロックをどれだけ正確に守れないか<rt>コンプライアンス</rt></ruby>の指標**になる
- **`G < 1` = 伝達が減る = 途中の関節が開いて一撃を吸収している** (`bulletref` 0.24 型)
- **`G > 1` = 末端が根元より速く回る = 過剰応答・共振** (当エンジン 1.62 型)

★**予測の構図**: **三者の分岐は「ロックをどれだけ正確に守るか」の差が利得に化けたものである。**
これは **J2 系の観察** (タスク126: 参照はロックを守り切らず角度が動く / タスク128: 三者が
間欠化の連続体上に並ぶ) と**同じ軸**であり、**本測定でそれが初めて「実測される量」になる。**

★**モデルZ の参照が `G = 1.00` だったことは、この検算と整合している** (参照は理論値どおり)。
**単純系で参照が `1.00` 付近に出れば、検算と実測が一致する。** 出なければ**検算か試料のどちらかが誤り**で、
その場合は**結果より先に検算を疑う** (本スレッドの教訓)。

## 6. 受入検査の更新 — ★**「回転あり」へ改訂**

| 項目 | 旧 (段差VMD) | **新 (回転パルスVMD)** |
|---|---|---|
| センター キー | `[0,300,301,1200,1201,2100]` (6 本) | ★**`[0,300,301,302,303,304,305,306,1200,1201,2100]` (11 本)** |
| センター **並進** | `X` が `0→0→STEP→STEP→0→0` | ★**全キーで `(0,0,0)`** |
| センター **回転** | ★**なし** (恒等四元数) | ★**あり (Z 軸のみ。`qx=qy=0`)**、累積角が上表の S 字 |
| `根元` | キー無し | **キー無し** (不変) |
| 鎖 | 34 本 × 2101 キー / 範囲 0..2100 | **不変** |

★**取り違え検査への影響**: 駆動が**並進から回転へ変わった**ので、
**既存の段差ベイクとは駆動区間で明確に分離する** (むしろ識別は容易になる)。
検査は従来どおり**駆動区間 (`F400-1200`)** で行う — `F0-300` は鉛直吊りで識別不能 (タスク120 の教訓)。
