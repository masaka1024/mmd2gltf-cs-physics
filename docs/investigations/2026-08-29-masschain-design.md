## 0. なぜ計器を替えるのか — タスク99 の3因を設計で潰す

| タスク99 で落ちた因 | 本設計での回避 |
|---|---|
| **参照の精度床** (`e_ang` が `%.7g` の下に沈み `β̂ang` が 1.0 へ飽和) | **段差駆動で大きな戻り事象を人工的に作る。** ピーク値が精度床の 100倍以上あることを番人で確認する |
| **slip に定常が来ない** (過渡長が指標で桁違い、窓が選べない) | **窓を探さない。** 事象の時刻 (段差の戻り) が設計で決まっているので、その直後の残差比だけを見る |
| **d=1.0 腕の凍結** (減衰1.0で毎ステップ速度ゼロ) | 試料の減衰を **0.5/0.5** にして clamp に触れさせない。d=1.0 と d=0.999 が**同一結果になるはず**という予測ごと検証する |

さらに、実モデルでは分離できなかった**質量ラダーの寄与**を、
**ラダー有り / 無しの2条件**で直接切り分ける。

## 1. 試料 — `chain_mode1.pmx` を基に2本作る

現物 `physics_probe/chain_mode1.pmx` (ボーン5 / 剛体4 / Joint3) の構成をそのまま使う:

- ボーン: `センター`(親なし) → `根元` → `鎖1` → `鎖2` → `鎖3`、リンク長 2.0、上端 y=12.0
- 剛体: `R0` = `根元` に mode0 (ボーン追従) / `R1..R3` = `鎖1..3` に mode1 (物理演算)
- Joint 0-2: **移動ロック (0/0/0)**、角度制限 X±80 Y±5 Z±10、**ばね 0**
- `group=0 / mask=0x0000` = **何とも衝突しない** (接触を混ぜない)
- 減衰 0.5 / 0.5

### 変更点 A — 質量ラダー

| 剛体 | 現行 | **ラダー版** | 比 |
|---|---|---|---|
| R1 | 1.0 | **5.559e14** | — |
| R2 | 1.0 | **1.853e14** | 1/3.0 |
| R3 | 1.0 | **6.177e13** | 1/3.0 |

比はモデルZ の鎖の実測値 (`5.55906E14 → 1.85302E14 → 6.17673E13 → 2.05891E13`) から取る。
**当てはめではなく、実モデルからの転記**である。

### 変更点 B — ★剛体をボーンからずらす (タスク98 の教訓)

現行の `chain_mode1.pmx` は**剛体をボーン位置ちょうど (オフセット 0.0000) に置いている**ため、
オフセットを使う位置再計算が**構造的に no-op** になり、効果を観測できなかった。

- **剛体 `R1..R3` の中心を、対応ボーンから `-Y` へ 0.5 ずらす** (リンク長 2.0 の 1/4)。
  モデルZ のスカートは 0.36〜0.55 のオフセットを持つので、その帯に入る。
- ずらしても Joint の位置 (ロックのアンカー) は**ボーン位置に置く**。
  こうすると「剛体中心 ≠ アンカー」になり、実モデルと同じ梃子が立つ。

### 作る2本 (どちらも同じ形状・同じ駆動。**質量の分布だけ**が違う)

| PMX | 質量 | 役割 |
|---|---|---|
| `chain_mass_flat.pmx` | R1=R2=R3=**5.559e14 (一様)** | **対照**。★**絶対量はラダーの先頭と同じにそろえる** |
| `chain_mass_ladder.pmx` | 上表のラダー (5.559e14 → 1.853e14 → 6.177e13) | **本命** |

★**flat 対照の質量は 1.0 ではなく 5.559e14 の一様に事前固定する** (2026-08-29 の明確化)。
1.0 にすると ladder との差分に「段差比 1/3」と「絶対量 14桁」が**同時に**入ってしまう。
一様巨大にそろえることで、**2本の差は段差比 1/3 だけ**になる。

### 第三点 — 絶対量の対照は既存ベイクを流用する (**新規ベイクは増やさない**)

絶対量 (巨大質量そのもの) の効きは、**既存の `chain_mode1.pmx` (質量 1.0)** と
その真OFF ベイク `chain_m1_off.vmd` (2026-08-28 取得済み) を**第三点として流用**する。

| 点 | PMX | 質量 | ベイク |
|---|---|---|---|
| ① 一様 1.0 | `chain_mode1.pmx` (既存) | 1.0 一様 | **既存 `chain_m1_off.vmd` を流用** |
| ② 一様 巨大 | `chain_mass_flat.pmx` (新規) | 5.559e14 一様 | 新規 (1本目) |
| ③ ラダー | `chain_mass_ladder.pmx` (新規) | 5.559e14 → 1/3 → 1/3 | 新規 (2本目) |

★**①だけは剛体オフセットが 0** (既存 PMX は剛体をボーン位置ちょうどに置いている)。
したがって **① と ②③ の差には「オフセットの有無」が交絡する**。

## 4. 計測量 — 戻り事象後の残差比 `r_k` (lockdrift 方式)

### 4-1. 違反量 `d`

移動ロック Joint のアンカー距離。**`lockdrift_onoff.py` の `joint_drift()` と同一式**を使う
(新しい物差しを作らない):

```
pA = posA + rot(qA, J_bind - boneA_bind)
pB = posB + rot(qB, J_bind - boneB_bind)
d  = |pA - pB|
```

bind で `d=0`、移動ロックが守られていれば常に 0。剛体オフセットは両側で相殺する。
仮定は「ボーンが剛体に剛に追従している (mode1)」1つだけで、本試料は mode1 なので成立。

### 4-2. 減衰係数 `a` — **単一減衰フィット** (v1.1 で改版。旧 `r_k` ピーク統計は廃止)

v1.0 は `lockdrift_onoff.peak_decay()` の局所ピーク統計を使う設計だったが、
**主区間 50 フレームに局所ピークが 3〜5 個しか立たず G5' が成立しなかった** (実測)。
この試料は減衰 0.5 で振動が速く収まるため、**ピークの個数を標本にする計器がそもそも合っていない。**
→ **ピークを数えるのをやめ、戻り事象1回を単一の指数減衰としてフィットする。**

**各 Joint × 各系について:**

```
t0    = F401..F410 の範囲で d(t) が最大になるフレーム            … 戻りの立ち上がり
t_end = t0 以降、d(t) が  10 * 精度床  を初めて下回るフレーム       ← v1.2: 絶対床のみ
        (上限 t0+30。それまでに下回らなければ t0+30)
fit   = ln d(t)  を  t - t0  に対して最小二乗 → 傾き k
a     = exp(k)                                            … 1サンプル(1/30秒)あたりの残存率
```

- **フィット標本が 4 以上**なら `a` を点推定として採る。
- **4 未満でも除外しない。上界として報告する**: `a ≤ (d(t0+k)/d(t0))^(1/k)` (k = 使えた区間長)。
- **H 判定は上下界で決まる対は決め、決まらない対だけ `H6''` (判定不能) とする。**
- 🚫 v1.1 の「5% 相対床」「除外が1Joint超で系ごと H6''」はいずれも廃止。
- 30fps サンプルで測る (VMD の native)。刻みの違いは `a_step = a^(1/N)` で併記する
  (N = 1/30 秒あたりのソルバステップ数: 参照 2 / 当エンジン 4 / `bulletref` 4)。
- 副計測 (飽和側の定常ズレ `d̄_sat`) は **F150..F400 の中央値**で従来どおり。

★`a` が小さいほど速く戻す = 引き戻しが強い。`β̂` とは向きが逆なので取り違えないこと。
★`d(t0)` の絶対値そのものは系ごとに違ってよい。`a` は**その系自身の d(t0) で正規化された量**である。

## 7. 事前登録の判定基準 (H1''〜H6'')

`a_ref` / `a_eng` / `a_bul` (§4-2 の単一減衰フィット) と、飽和側の定常ズレ `d̄_sat` (F150..F400) で判定する。
**境界値は v1.0 と同一。後から動かさない。** `ladder` 版を主、`flat` 版を対照とする。
(記号を H1'→H1'' と改めたのは計器が変わったことを示すためで、**閾値は 1 つも変えていない**。)

| # | 条件 (ladder 版) | 読み | 次 |
|---|---|---|---|
| **H1'** | `a_eng ≤ a_ref / 2` (当エンジンが**速く戻す**) かつ `d̄_sat,eng << d̄_sat,ref` | **引き戻しが強すぎる。** 硬さの正体はロック行の引き戻し率 | 反復回数 / ERP / CFM相当の欠如 / 行数 へ絞る |
| **H2'** | `a` が同等 (±20%) かつ `d̄_sat,eng << d̄_sat,ref` | **引き戻しは同等で、そもそも励起が入っていない** | warm-start 0.85 / `SpringAsMotorRow` / 外力の伝わり方 へ |
| **H3'** | `a_eng ≥ a_ref × 2` (当エンジンが**戻さない**) | 引き戻しは硬さの説明にならない | 行数・行の作り方へ |
| **H4'** | `a_bul ≈ a_ref` (±20%) で `a_eng` だけ外れる | **当エンジン固有** | 行レベル突合を続行 |
| **H5'** | `a_bul ≈ a_eng` で2つとも `a_ref` から外れる | **Bullet と PMXe の差** | NORTH_STAR 原則3 (参照が人工物か) を先に決める |
| **H6'** | 番人のいずれかが落ちる / G5' が STEP 切替後も不足 | **判定不能** | 数値を出さずに報告して止まる |

### 質量の寄与の読み — **三点で分ける** (上とは独立に登録)

① 一様 1.0 (既存流用・**オフセット 0 の交絡あり**) / ② 一様 巨大 / ③ ラダー。
「①→②」が**絶対量**の効き、「②→③」が**段差比 1/3** の効き。

| 観察 | 読み | 次 |
|---|---|---|
| ①≈② で **②→③ だけ割れる** | **段差比 (質量比) が原因。** 絶対量そのものは無害 | 実効質量 `1/(Σ invMass)` の桁落ち / ロック行の質量重み付けへ |
| **①→② で割れ**、②≈③ | **絶対量 (巨大質量) が原因。** 段差比は無関係 | `invMass` が極小 (≲2e-15) の動的剛体の扱いへ (タスク95 の所見と接続) |
| ①→② でも ②→③ でも割れる | 両方効く。**寄与の大きさを比で報告**し、大きい側から潰す | — |
| **三点とも同じだけ割れる** | **質量は無関係。** 硬さはロック行の作り方そのもの | 行数・行の作り方・warm-start へ |
| ③ でのみ当エンジンが破綻 (NaN / 発散) | **破綻の再現最小系が得られた。それ自体が成果** | 最小系での二分に切り替える |

★①は**オフセット 0 の交絡**を含むので、「①→② で割れた」場合は
**絶対量とオフセットのどちらかを分離できていない**。その場合に限り、
オフセットをそろえた一様 1.0 版の追加ベイクを依頼する (事前登録)。
