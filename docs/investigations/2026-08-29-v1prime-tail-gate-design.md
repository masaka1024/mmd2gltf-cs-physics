## 2. ★指標を**数値で固定する** (実測前・事後変更禁止)

前回の失敗 (`rel(0)` 基準) を繰り返さないため、指標は次の 3 条件を満たすものだけを使う:

1. **`f0` に依らない** (恒久ルール)
2. **定数オフセットに依らない** (`bulletref` は**剛体**姿勢、参照/当エンジンは**ボーン**姿勢。
   タスク121 で `|rel(F)|` に 8.25° のオフセットが乗ることを実測済み)
3. **起動過渡 `f0`〜`f11` を窓から外す** (台帳 L2966/L2981)

### 2-1. 基本量

`u_j(F) = |rel_j(F)|` = Joint `j` の親子相対回転角 [deg]。
`rel_j(F) = q_parent(F)⁻¹ ⊗ q_child(F)`。**`f0` を一切参照しない。**

### 2-2. ★オフセット除去 — **自アーム・自 Joint の中央値を引く**

```
    m_j  = median_F u_j(F)          (窓内・そのアーム自身の値)
    e_j(F) = u_j(F) − m_j           ← 裾指標の基本量
```

`bulletref` の定数オフセットは **Joint ごとに一定**なので `m_j` に吸収され、`e_j` から消える。
`f0` も窓から外れているので効かない。

### 2-3. 判定量 (2つ。両方を出し、**主は E**)

| 記号 | 定義 | 位置づけ |
|---|---|---|
| **E (主)** | **`m_j + T` を超えたサンプル数の割合** (全 Joint × 全フレーム) | **イベント計数。** 「開くか開かないか」を直接数える |
| **P (従)** | `e_j(F)` の **p99** (全 Joint × 全フレームをプールして) | 連続量。E が 0 に潰れたときの補助 |

### 2-4. ★閾値・帯・窓 — **すべて既存定数の流用。新設しない**

| 項目 | 値 | 根拠 |
|---|---|---|
| **閾値 `T`** | **0.280 deg** | **既存の `slip` 打ち切り床** (= 10 × 精度床 0.0280)。**本データに当てて決めた値ではない** |
| **帯** | **±30%** | 既存流用 (タスク106 の `d̄` 帯) |
| **平時窓** | **F12-699** | 起動過渡 `f0`〜`f11` を除く / `f784` の**十分手前**で打ち切る |
| **全尺窓** | **F12-999** | 裾イベントが実在する全区間 (破綻域を含む) |
| 集計単位 | 全 Joint (33 関節) × 全フレームをプール | タスク121 と同じ |

### 2-5. ★集計の形を固定する (2026-08-29 追記・**再集計の前**)

| 位置づけ | 集計 |
|---|---|
| **主判定** | **鎖 34 本 (33 関節) を<ruby>プール<rt>合算</rt></ruby>した `E`** — アームごとに **1 値**。裾イベントは間欠なので **Joint 単位では `E` が 0 に潰れて比が作れない**恐れがあり、プールが安定 |
| **従** | **Joint 別の内訳表。** 参照側の**イベント数が窓内 `N = 5` 件未満**の Joint は **判定不能 = カバレッジ報告** (①以来の型) |
| **合否** | **プール `E` の ±30%** で判定。**Joint 別は分布の観察として併記** (どの Joint が開くか = 機序調査の入口情報) |

★`N = 5` も本データを見ずに固定した値である。

★**`T = 0.280` を選ぶ理由**: 既に設計書へ数値固定済みの定数で、**今回のデータを見て決めていない**。
(観測値を見てから閾値を選ぶと、それ自体が artifact を作る。本スレッドで4回踏んだ型を避ける)

| 記号 | 条件 | 停止のしかた |
|---|---|---|
| **V1' 成立** | **`bulletref` の E が 参照の E の ±30% 以内** (平時窓 F12-699 が主。全尺窓は併記) | **神託代理つきでイベントの機序調査へ。** どのフレーム・どの Joint・接触インパルスとの相関を見る。**`ROWTRACE` 配線の条件付き事前決裁はこちらへ引き継ぐ** |
