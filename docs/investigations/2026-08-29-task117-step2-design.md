## 3. 判定条件の**事前固定**

### 3-1. `SubSteps` — ★**判定は t3 当時条件 (`SUBSTEPS=2`)**

t3 走行ログは `刻み 1/60 x SubSteps2 / Iters10`。
**`f784` は当時条件で観測された症状**なので、**同一性を優先して当時条件を判定側に置く。**
整合構成 (`SUBSTEPS=1` + `JBETA=0.5` + `JOINTORDER`) は**並記観察のみ**、判定には使わない。

### 3-2. ★事前登録の**前提分岐** (手順1 の知見から必ず先に見る)

手順1 で、**素の既定構成 (実効120Hz・`Beta` 0.2) では静置でクランプが不発**と分かった。
当時条件 = その素の既定構成である。したがって**駆動下で発火するかどうかは未知**であり、
これが (i)(ii) の成否より**上位の前提**になる。

| 前提 P | 観測 | 読み |
|---|---|---|
| **P-発火** | 当時条件の走行で `bias` が 10 に張り付く行が**存在する** | (i)(ii) を予定どおり実施 |
| **P-不発** | 一度も張り付かない | ★`MAXCORR=1e9` は**ビット同一**になるはずで、`f784` は消えない。→ **「`f784` は `MaxCorrectionVel` 由来ではない」で即決着**し、そこで停止する |

**P は `ROWTRACE` ではなく `MAXCORR` の A/B md5 で判定する** (`divhunt` に `ROWTRACE` が無いため)。
md5 が動けば P-発火、ビット同一なら P-不発。**これは (i) を走らせる前に見る。**

### 3-3. 窓 — **t3 当時の突合方法をそのまま踏襲**

- 参照は **60Hz インデックス 0..999**。**`f784` は尺内 (13.07 秒地点)** なので窓の外挿は不要。
- 突合は `t3/three.py` (`slip(t) = angle(rel(t)·rel(0)⁻¹)` / `w(t) = angle(q(t-1)⁻¹·q(t))`) を**非改変で使う**。
  ★**`rel(0)` 基準である点は当時のまま**にする (段階①②で `bind` 基準へ改めたのは別系統の物差し。
  **当時の症状を当時の物差しで見る**のが (i) の目的なので、ここで物差しを変えない)。
- **(i) の窓** = `f770〜f800` (スパイク前後)。**(ii) の窓** = `f0〜f999` の全尺 (統計)。
- 鎖は **35本全域**で取る (参照に 35本すべてが入っているため、`鎖L` 限定にしない)。

### 3-4. 判定量と帯

| | 判定量 | 帯 |
|---|---|---|
| **(i) 主** | `f784` のスパイク (当時値 **`|v| = 4.465` / 角度 `36.15°`**) の**消長** | 消える / 遅れる / 不変 の三択。数値帯は置かない |
| **(ii) 本丸** | `slip` 統計 (中央・p99・最大) の **当エンジン/参照 比** | **±30%** (既存流用・新設しない) |
