# 摩擦合成方式の神託チェックシート

**目的**: MMD / PmxEditor が 2剛体の摩擦係数をどう合成しているかを、**滑る / 止まる の目視だけ**で特定する。

なぜ要るか: 当エンジンの既定は **幾何平均** `√(f0·f1)`、Bullet 2.75 は **積** `f0·f1`
(`btManifoldResult.cpp:26`)。この差でもみあげが参照の 2.24 倍動いた。
どちらが MMD に合っているかを推測でなく実測で決める。

---

## 見かた

傾いた板の上に箱を置いてあるだけのモデル。ジョイントは無い。
**滑るかどうかは `tanθ` と実効摩擦 μ の大小だけ**で決まる (`tanθ > μ` なら滑る)。
合成方式ごとに μ が違うので、θ を候補値の間に置くと二値で割れる。

- 物理を有効にして **1〜2秒**見るだけでよい。動き出せば「滑る」、その場に留まれば「止まる」。
- 滑る場合は板の外まで一気に飛んでいく (tan0.80 で 2秒に 125 単位)。**動き出したか否か**だけ見ればよい。
- 箱は扁平で重心が低いので、転がりではなく滑りだけが起きる。

## 画面に何が見えるか

**★MMD は物理演算中のボーンマーカーを描かない**ので、形状を入れてある。色で見分ける。

| 色 | 何 | 動くか |
|---|---|---|
| **灰色の板** | 坂 (静的) | 動かない |
| **赤い薄板** | 出発点マーカー | 動かない |
| **青い箱** | 動的剛体 | **これが動くかどうかを見る** |

青い箱が赤い板の上に載ったまま → **止まる**。赤い板から出ていったら → **滑る**。
滑るときは坂の外まで一気に飛んでいく (tan0.80 で 2秒に 125 単位) ので、見逃しようがない。

## 手順

1. **PmxEditor** … 各 PMX を開く → TransformView → 物理演算 ON → 1〜2秒 → 表に記入。
   可能なら **[ボーン位置合わせ再計算] を OFF と ON の両方**で見る (補正層の影響の有無)。
2. **MMD 本体** … 同じ PMX を読み込む → **[物理演算] を「常に演算」**にする → 再生 → 表に記入。
   ★**PMXe と MMD の摩擦が同一という仮定自体が検証対象**なので、両方あると価値が高い。
   ★MMD では物理で動くボーンのマーカーが消える。**青い箱そのものを見ること。**

## 判定表 (記入後、当てはまる行が答え)

**#1, #2, #3, #4 の4つ**で方式が一意に決まる。

| 方式 | μ(A) | μ(B) | #1 A0.35 | #2 A0.55 | #3 A0.80 | #4 B0.35 |
|---|---|---|---|---|---|---|
| **積** `f0·f1` (= Bullet 2.75) | 0.25 | 0.25 | 滑る | 滑る | 滑る | **滑る** |
| **幾何平均** `√(f0·f1)` (= 当エンジン既定) | 0.5 | 0.5 | 止まる | 滑る | 滑る | 止まる |
| **算術平均** `(f0+f1)/2` | 0.625 | 0.5 | 止まる | 止まる | 滑る | 止まる |
| **min** | 0.25 | 0.5 | 滑る | 滑る | 滑る | 止まる |
| **max** | 1.0 | 0.5 | 止まる | 止まる | 止まる | 止まる |

- **#4 が「滑る」なら 積で確定** (積だけが B で滑る)。
- #4 が「止まる」なら #1〜#3 で 幾何 / 算術 / min / max を分ける。
- #5・#6 はどの方式でも「滑る」。**装置が壊れていないことの確認用**なので、
  ここが「止まる」と出たら観測条件がおかしい (物理が止まっている等) を疑うこと。

# 第2ラウンド — 「全部滑る」の裏取り

第1ラウンドの観察は **全6件「滑る」** だった (2026-08-23, MMD/PMXe)。
候補5方式のうちこれに当てはまるのは **積 (= Bullet 2.75 と同じ)** だけである。

**ただしこの装置は「摩擦がまるで効いていない (μ≈0)」場合も同じ「全部滑る」を出す。**
そこを切り分けないと「積」と言い切れないので、浅い角度を並べて
**止まり始める角度から μ を直に読む**。対B (坂 0.5 / 箱 0.5) だけを使う。

| # | ファイル | tanθ | θ | 観察 |
|---|---|---|---|---|
| 7 | `fric_L_tan030.pmx` | 0.30 | 16.7° | ☐滑る ☐止まる |
| 8 | `fric_L_tan022.pmx` | 0.22 | 12.4° | ☐滑る ☐止まる |
| 9 | `fric_L_tan015.pmx` | 0.15 | 8.5° | ☐滑る ☐止まる |
| 10 | `fric_L_tan008.pmx` | 0.08 | 4.6° | ☐滑る ☐止まる |

## 判定

| 観察 | μ | 意味 |
|---|---|---|
| #7 滑る / #8 止まる | **0.22 〜 0.30** | **積 (0.25) で確定。** 第1ラウンドの読みが裏付けられる |
| #7#8 滑る / #9 止まる | 0.15 〜 0.22 | 積より小さい。別の規則 (積 × 何か) を疑う |
| #7#8#9 滑る / #10 止まる | 0.08 〜 0.15 | かなり小さい。ほぼ「摩擦を弱く扱っている」 |
| **全部 滑る** | **< 0.08** | **摩擦がほぼ効いていない。** 第1ラウンドの「積」という読みは**取り下げ** |

## 較正 (当エンジンで確認済み)

| | #7 0.30 | #8 0.22 | #9 0.15 | #10 0.08 |
|---|---|---|---|---|
| `FRICMUL=1` (積 μ=0.25) | **滑る** 9.80 | 止まる 0.16 | 止まる 0.12 | 止まる 0.04 |
| 既定 (幾何平均 μ=0.5) | 止まる 0.11 | 止まる 0.02 | 止まる 0.02 | 止まる 0.05 |

μ=0.25 の境目が **0.22 と 0.30 の間**に正しく出ている。装置は μ を挟めている。

# 結果 (2026-08-23 ユーザー実測・決着)

| ラウンド | 観察 |
|---|---|
| 第1 | **全6件 滑る** |
| 第2 | **#7 (0.30) 滑る / #8 (0.22) 止まる / #9 (0.15) 止まる / #10 (0.08) 止まる** |

→ **μ = 0.22〜0.30**。摩擦対は (0.5, 0.5) なので、
**MMD/PmxEditor の摩擦合成は 積 `f0·f1` = 0.25。Bullet 2.75 と同じ。**
当エンジン既定の幾何平均 `√(f0·f1)` = 0.5 の方が誤りだった。

「摩擦がまるで効いていない (μ≈0)」の可能性は第2ラウンドで排除済み
(μ≈0 なら 0.08 でも滑るはずだった)。

## 次に立った問題

もみあげ (`friction=0.5`) の正しい μ は 0.25。**MMD はその μ で参照 (=1.00) を出す**のに、
**当エンジンは同じ 0.25 で 2.24 倍動く**。つまり *同じ摩擦係数でも当エンジンの方がよく滑る*。
既定の幾何平均 (μ=0.5) は、その滑りすぎを μ を倍にして**相殺していただけ**だった。

→ 新スレッド「同じ μ でも当エンジンの方がよく滑る」を台帳へ登録した。
